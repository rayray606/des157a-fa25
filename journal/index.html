There are seven important game design principles in order to give players an enjoyable gaming experience.

  • 1. Set Clear Goals and Objectives
    • It provides a pathway for players to follow in the game. A game has a primary goal and many small ones. The primary goal is to complete the game, while the small one motivates the player towards the primary goal.
  • 2. Engaging Core Mechanics
    • This is the building block for the game; simple and engaging.
  • 3. Maintain Game Flow and Player Experience
    • Have a consistent flow to have a seamless playing experience.
  • 4. Balancing the Game
    • This can be subjective.
  • 5. Offer Feedback and Rewards
    • Creates a great engagement for the audience.
  • 6. Playtesting
    • One of the important processes is playtesting to check if the game is fun or not.
  • 7. Sound Design
    • Sound and video games can go hand in hand. Technically not a game design, but quite important.

Overuse of Overlays

An overlay is a content box that displays on top of another page. When this technique was first introduced, designers adopted lightboxes with vengeance. Sometimes the overlay has so much content that it needs a scrollbar and requires a lot of scrolling just to get to the bottom. To minimize the scroll, adding anchor links can send users directly to the content. Overuse of Overlays: How to Avoid Misusing Lightboxes

Many designers use a guideline when using overlays: 'visible close button,' distinct from the background, and accessible to keyboard users. But just because you follow all these guidelines, it can be unnecessary at times. Just because you can doesn't mean you should. Consider these questions:

  • Who is the target audience?
  • What action is the user supposed to take?
  • When will the overlay appear, and will it be an interruption?
  • Where will the overlay appear on the page?
  • Why does this need to be an overlay instead of within a page?

WHO: Blocking access to the content. Consider users who are on a mobile device.

WHAT: To read text or view images, to complete a form, and to make a decision.

WHEN: To maintain the context of the current screen.

WHERE: Lightbox content should appear directly in the user; line of sight

WHY: To showcase the serious consequences, and if it is urgent.

Best Practices for Form Designs

There are many practices for form design. One of them is minimizing the Input fields: don't overcomplicate things and keep the relevant information. One Column Layout helps the form process faster and flows better. Multiple Steps are used when there are times when we can't minimize the number of fields. By making the form into several steps, it can help the user have less cognitive load and visual noise. Asking easy questions first can increase the chances for the user to fill out the form; the chances for abandonment are low this way. Having a placeholder text in the field can help the user to put in the right information. Sizing the fields accordingly may abandon the symmetry of the design, but it fails the purpose of a form. For example, the email input can have around 40 characters, but the zipcode has 5 characters. Providing a show password option can help users not to retype the password in the wrong form. Never use a Reset or Clear button because users just refresh the page. The usage of a button like that can render it inconsequential and unnecessary. It's ultimately a waste of time for both the user and the designer. Most importantly, accessibility for all users to be able to use and have access to the site; big, readable fonts, screen reader, and proper contrast.
